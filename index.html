Telugu Bible Puzzle — Letter Scatter

The page automatically loads template.png from the same folder as this HTML file. Enter the verse, review the Telugu written units, and scatter them in the puzzle area.

Accuracy: Telugu text is preserved as entered in the unit list. Automatic splitting is only a starting point; always review the units before generating.

1. Template

Uses template.png from the same folder. To change the design, replace that file in your GitHub repository using the exact filename template.png.

2. Template design

Upload your white-design template, then choose the color to apply to its white design elements. The puzzle number is drawn over the template; adjust its position below to fit the number badge.

3. Verse and units

Each line is one puzzle piece. The first line is highlighted yellow and appears only once. Spaces and punctuation should not be included. Keep vowel signs and consonant clusters with their intended unit.

Letters are shuffled first. Short verses (up to 15 units) use the reference layout: corners, top/bottom middle, two on each side, above/below and beside the yellow center. Longer verses fill balanced rows with the yellow unit centered and shrink the letters to fit.

4. Puzzle area (%)

These defaults fit the usual framed template; adjust if needed so letters stay inside the black area.
