1. Template

Uses template.png from the same folder. To change the design, replace that file in your GitHub repository using the exact filename template.png.

2. Template design

Upload your white-design template, then choose the color to apply to its white design elements. The puzzle number is drawn over the template; adjust its position below to fit the number badge.

3. Verse and units

Each line is one puzzle piece. The first line is highlighted yellow and appears only once. Spaces and punctuation should not be included. Keep vowel signs and consonant clusters with their intended unit.

Placement order: four corners, top/bottom center, two positions on each side, above/below the yellow center, left/right of the yellow center, then remaining spaces. Letters are shuffled before being placed.

4. Puzzle area (%)

These defaults fit the usual framed template; adjust if needed so letters stay inside the black area.
